# Arc Swipe Navigation

Мод для Zen по референсу Arc: большой полупрозрачный тёмный полукруг
выступает из края страницы, внутри — толстая белая стрелка с округлыми концами.
Для перехода вперёд индикатор зеркально отражается справа.

Индикатор плавно выезжает из края за 240 мс. Прозрачность фона зависит
от длины свайпа: в начале фон прозрачный, на половине пути — половина
текущей насыщенности, при достижении порога перехода — полный тёмный цвет
(88% непрозрачности). При движении обратно фон снова бледнеет.
При отпускании индикатор исчезает за 180 мс.
Цвет одинаковый в светлой и тёмной теме, без голубой подсветки.

Чувствительность, направление, отмена и переходы по истории остаются штатными.
Мод не добавляет индикаторы для кнопок панели, клавиатуры или кнопок мыши.
Небольшой `progress.uc.js` передаёт прогресс штатного жеста в CSS.
Он не меняет навигацию, чувствительность и порог перехода.

Репозиторий и ID `chrome-swipe-navigation` сохранены для обновления ранее
установленного мода; отображаемое название изменено на **Arc Swipe Navigation**.

## Установка через Sine (GitHub)

1. Откройте **Настройки Zen → Sine Mods**.
2. Вставьте в поле установки из GitHub:

   ```text
   https://github.com/b2theh/ChromeSwipeNavigation
   ```

3. Установите или обновите мод, разрешите JavaScript для него в Sine
   (если появится запрос) и полностью перезапустите Zen.

Начиная с версии 1.2.0 для зависимости прозрачности от свайпа нужен JavaScript.
Без скрипта сохраняется оформление с постоянным тёмным фоном.
Если раньше добавляли ручной импорт, удалите его перед установкой через Sine.

## Ручная установка

1. В `about:config` включите
   `toolkit.legacyUserProfileCustomizations.stylesheets`.
2. Убедитесь, что `browser.history_swipe_animation.disabled` имеет значение `false`.
3. Откройте папку профиля через `about:support` → «Папка профиля».
4. Скопируйте папку `ChromeSwipeNavigation` целиком в папку `chrome` профиля.
5. В начало `chrome/userChrome.css`, перед обычными правилами, добавьте:

   ```css
   @import url("ChromeSwipeNavigation/chrome.css");
   ```

6. Для зависимости прозрачности от прогресса нужен загрузчик userChromeJS:
   подключите `progress.uc.js` через него. В Sine скрипт подключается автоматически.
7. Полностью перезапустите Zen и сделайте горизонтальный свайп двумя пальцами
   на трекпаде на странице с историей переходов.

Отключите другие моды оформления свайпа, если они установлены.
Файлы `chrome.css` и `arrow.svg` должны оставаться рядом.
Для удаления уберите импорт и перезапустите браузер.
При установке через Sine мод можно отключить или удалить в настройках Sine Mods.

## Настройка

В начале `chrome.css`:

- `--arc-swipe-size`: диаметр круга (152px).
- `--arc-swipe-reveal`: видимая ширина у края (70px).
- `--arc-swipe-arrow-size`: размер стрелки (48px).
- `--arc-swipe-arrow-inset`: отступ стрелки от края (10px).
- `--arc-swipe-surface`: тёмный полупрозрачный фон.
- `--arc-swipe-enter-duration`: длительность появления (240ms).

Перемещение использует текущие настройки `browser.swipe.navigation-icon-*`.
При включённом уменьшении движения выезд отключён, исчезновение сокращено.

## Проверка

Селекторы, атрибут `collapsed`, управление смещением
и завершение через `transitionend` сверены с кодом установленного Zen **1.24b**
на macOS. Оформление не меняет обработчики жестов и настройки профиля.
На других платформах индикатор доступен только там, где сам Zen поддерживает
штатную анимацию свайпа.

Визуальную проверку выполняет пользователь: назад/вперёд, короткий отменённый
свайп, смена направления до отпускания, повторные быстрые свайпы, светлая/тёмная
тема и разделённый просмотр. Браузер автоматически не запускался.

Автоматические проверки: `node --test tests/progress.test.cjs` — оба направления,
порог перехода, уменьшение прогресса, отмена, сохранение штатного исчезновения
и повторная загрузка/отключение скрипта.
